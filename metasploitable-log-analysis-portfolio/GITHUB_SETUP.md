# GitHub Setup

## Option 1: Upload through GitHub website

1. Create a new GitHub repository.
2. Name it something like:

```text
metasploitable-log-analysis-portfolio
```

3. Upload the contents of this folder.
4. Commit the files.

## Option 2: Push from the command line

```bash
cd metasploitable-log-analysis-portfolio
git init
git add .
git commit -m "Add Metasploitable log analysis portfolio project"
git branch -M main
git remote add origin https://github.com/<your-username>/metasploitable-log-analysis-portfolio.git
git push -u origin main
```

## Suggested Repository Description

```text
Portfolio project documenting hands-on Apache and Linux authentication log analysis using Kali Linux and Metasploitable.
```
